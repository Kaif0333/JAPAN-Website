# Japan Tours - Landing Page

Welcome to the official frontend repository for **Japan Tours**, a stunning landing page showcasing travel experiences in Japan.

![Japan Tours](/public/images/contact-bg.jpg)

## 🌐 Live Website
The website is deployed and live at:
- **[Japan Tours Live Site](https://japan-website-work.vercel.app/)**

## 🚀 Key Features
- **Premium Aesthetics**: Built with high-quality videos, fluid animations, and a polished UI.
- **Engaging Interactions**: Includes custom cursors, parallax scrolling, and stagger animations.
- **Modern Layout**: Features a hero video background, interactive timeline, and elegant forms.
- **Fully Responsive**: Flawless experience across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 & Vanilla CSS
- **Animations**: GSAP (GreenSock) & Lenis Smooth Scrolling
- **UI Components**: Custom-built premium components
- **Deployment**: Vercel

## 💻 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/Kaif0333/JAPAN-Website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd JAPAN-Website
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
